# Published Source Code

This release includes code used to manage the autonomous NV experiments and
analyze their data, along with a summary of the agent's instructions.

## Included Source

- `python/openclaw_nv_execution_source/`
- `python/openclaw_runtime/`
- `matlab/analysis/`

These are sanitized copies or public summaries. Local paths have been replaced
with placeholders.

## Execution Guard

Direct CLI execution is disabled in the Python files that would control
experiments. See [Public scope](public_scope.md) for the full release contents.
