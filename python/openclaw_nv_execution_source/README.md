# Production Source Copy

This directory contains source code used by the three public case studies:
the project manager, batch runner, bridge monitor, and helpers for adding jobs
to the queue. Private local settings have been removed.

These files are included so readers can inspect the production architecture.
Direct CLI execution is disabled in this public release.

Local paths have been replaced by placeholders such as `<OPENCLAW_WORKSPACE>`,
`<MATLAB_23C_ROOT>`, and `<NV_BRIDGE_ROOT>`.

See [Public scope](../../docs/public_scope.md) for the included and excluded
components.
